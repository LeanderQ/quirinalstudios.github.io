An app for reading the manuscripts. Early sketch.

I've been putting together an idea for an iOS app for studying and training from the source manuscripts — Fiore to start with, but built so other treatises can go in later. Nothing is built yet. These are clickable sketches, not a working app.

I'd rather find out now if this is useful or if I'm designing something only I want. Blunt is more useful than kind here.

How to reply

There are numbered questions throughout. Answer any of them in the chat — just the number and a few words is perfect. "6 — I'd never use that" is a genuinely useful reply.

Ignore the ones you don't care about. You don't need to go in order, and you don't need to be nice about it.

Some things are tappable. The Italian text is placeholder — don't read it for accuracy, I've not transcribed anything properly yet.

Before you scroll

These four are about what you already do. They're the most useful answers I can get, and seeing the sketches first will change how you answer them — so if you can, do these before scrolling on.

Reading a play

The idea is that the manuscript stays on screen at all times, and everything else — original text, translation, your own notes, the other copies — sits alongside it. Tap a play on the page to move between them.

Your own notes

During class

I always see people with books propped open, moving back and forth to check something. This is a stripped-back view for a phone or tablet propped on a bench — big type, no clutter, one play at a time, thumb-sized buttons.
